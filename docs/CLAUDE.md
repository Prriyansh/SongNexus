# docs/

Documentation, not application code. Nothing here is built, served or tested.

## Files at this level

- `CLAUDE.md` — this guide.
- `architecture.md` — how the app works: frontend overview, data sources, comparison features,
  rate limiting and caching. Keep it current when those change (unlike the folders below).

## Folders

- `design/` — Helen's design handoff: the integration guide she wrote and five reference screenshots.
- `prototype/` — the first clickable HTML mockup, made from the team's paper sketches.

When the app changes in a way that affects these documents, add a dated note at the top of the
relevant README instead of rewriting the original; they record decisions as they were made.
